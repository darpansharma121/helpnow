# Features

## Included in the hackathon MVP

| Feature | Description |
| --- | --- |
| Help request creation | Capture title, description, category, urgency, and approximate location. |
| Nearby discovery | Browse active requests in a filterable feed and map view. |
| Request lifecycle | Open, accepted, in-progress, resolved, and cancelled states. |
| Helper acceptance | A signed-in helper can take ownership of an open request. |
| Real-time updates | New and updated requests appear without refreshing. |
| Basic safety controls | Required fields, rate limiting, and simple spam/abuse reporting hooks. |

## Explicitly out of scope for the MVP

- Medical or emergency dispatch
- Payments and service pricing
- Full background verification
- In-app chat, voice calling, or payment workflows
- Government/NGO integrations

## AI-assisted enhancements

If an API key is available, AI can suggest a category and urgency from the request text, create a short helper-facing summary, and flag likely spam. Human-visible request content remains editable; AI never makes emergency decisions.
